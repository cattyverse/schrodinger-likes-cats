# Schrödinger Likes Cats

"猫好きなシュレディンガー"企画書

何を作るかはここに書く。技術的な持ち方は `docs/概要説明.md`。幅・密度・カードの中の書き方は `docs/レスポンシブ.md`。

---

## コンセプト

遊び場となるようなサイト。いちばんのコンセプトは、**無限の真っ白な空間に展示を置いている**こと。Web はその空間を覗く窓にすぎない。いま主に覗くのはスマホなので、見える形は縦の無限スクロールになる。空間が縦なのではなく、窓が縦なだけ。レイアウトの基準もスマホ。PC で大きくなっても違和感がない程度に止める。PC 向けに使いやすくすることは、今はやらない。

空間を見る順は人それぞれなので、トップの順はランダムで合わせている。新着の列を作っているのではない。

記事を並べるブログではない。名前どおり、猫好きなシュレディンガーが顔である。サイトの印象は、メイン展示のシュレ猫でつける。本体はそこではなく、順次追加していく展示物（論理クイズ、モンティホールの視覚化、など）。

## 訪問者の流れ

1. トップのカード一覧で見つける（偶然）
2. カードの予告で興味を持つ
3. More で開いて、その場で遊ぶ
4. 解説から詳細を読み、関連から次の展示へ行く（編集した道）
5. タグを押して、同じ系統を新しい順に見る（体系）
6. ナビのカタログから、狙った部屋へ行く
7. 実験場で、まだ展示になっていない案を読む
8. この場所が何かを、about で読む

入り口は経路で違う。

- 検索: 詳細。`/{slug}` が本体
- SNS: メイン（トップ）が多い。詳細や、カタログ（`/?catalog=`）へ直に来ることもある
- 無いアドレス: 404 専用画面。シュレ猫の遊びだけ

サイト内検索は持たない。トップのランダム列に「最新」「人気」は出さない。見る順は各自に任せるため。登録日の降順で全部見たいときだけ、ナビの「新着」（`/?order=published`）へ行く。体系的に見る基本はカタログである。部屋の見方にきれいなページ URL は作らない。`?catalog=` と `?tag=` のように、一覧へ印を付ける。

実体のあるページは次のとおり。


| 場所      | 役割                                  |
| ------- | ----------------------------------- |
| 展示（トップ） | カード一覧。予告の動き。More で遊びをその場に出せる         |
| 詳細      | 遊びと説明と関連。検索の着地                      |
| 関連      | 次の展示へのリンク。片方向でよい                    |
| カタログ    | 部屋。入口はナビの `#クイズ` など。`?catalog=`。配下のタグで絞る |
| タグ      | そのタグの展示一覧。登録日の新しい順。`?catalog=&tag=`     |
| 実験場     | 案をつらつら書く場所。展示のカード一覧には出さない           |
| について    | about us。CATC を載せる                  |
| 404     | 専用画面。無いアドレスの着地。窓枠なし。頭の中央に 404 Not Found。シュレ猫の遊び。下に Back Home。詳細ではない |

## トップ

アクセスすると、無限の展示空間を縦に覗く。下へ行くと、まだ見ていない展示のカードを読み込む。一度出したカードは消さない。開いた遊びも、高さが展示ごとに違っても残る。追加できる回数には上限がある（技術側）。

- 1 つ目は固定でシュレ猫（顔なので、窓のすぐそこに置く）
- 2 つ目以降は、その人の覗き順として乱数で決まる。アクセスのたび。URL には残さない。リロードで変わる
- 閉じたカードでは箱を持ち上げない。More で開くと、詳細と同じ遊びがその場に出る
- 同時に開くカードを開ける。状態は保存
- 並びは常に 1 列。カードには最大幅がある（864px。FHD の 45%）。窓がそれより狭いときは全幅（スマホ、多くのタブレット）。広いときは最大で止まり、中央。左右は白いキャンバス。横持ち専用の形にはしない
- 出す枚数は、窓を埋める計算。最低 12、足りなければ 12 の倍数。カードが無い初回は 12。出してから実測し、まだ埋まっていなければ足す。追加も同じ式。幅が変わっても一度出したカードは残す。スクロール位置を 12 行グループで戻すのは後回し
- 下まで来ると足す。スクロールの手段は問わない。ローディング（よくある回るやつ）のあいだに HTML を全部取り、揃ってから一気に出す。画像は待たない。最低 0.5 秒は出す。20 回目を足した時点でフッター

## カード

記事のサムネイルではない。空間に置いた展示物そのもの。**カード全体を囲う外枠は持たせない。** パネルの線で箱型にしない。白い空間に、説明・中身・タグが乗る。タイトルは中身の1枚目。末尾の More で開く。開いたら4コマは残し、下に遊びと解説を足す。一歩スクロールしたあとのキャンバスを、カードで分割しない。

中身は、一番狭い幅（360 CSS px）で組む。広くなっても並びは変えない。窓の幅で形を切り替えない。画面の絵は線画のイラスト。SNS のプレビューだけ、別の横長画像（PNG）。

タイトルや説明、タグ、解説には、見やすさのために必要な装飾（文字の地、余白、コントラストなど）を付けてよい。囲いの装飾と、読めるための装飾は別。説明は説明のまま。見出しにしない。ただし一覧で先に目に入るので、本文より大きく、上下に余白を取る。

並びは次のとおり。

- 説明
- 中身。予告の動き。1枚目はタイトル（`framesTemplate` の先頭。見た目は展示ごと）。そのあと4コマ風（2〜4枚を順に移す）を共通の型にする。次のコマは下からせりあがって、今のコマを押し上げる。最後の次も同じ押し上げでタイトルに戻る。開いても残す
- タグ
- More（二重の下向き V。四角で囲う。カードの一番下。左右は線）

More を押すと、タグの下に遊びと解説が出る。4コマは消さない。高さは伸び縮みする。More は同じ場所で閉じる印（上向き）になる。詳細ページへは行かない。押した瞬間の反応（印が向きを変える）で、開いたと分かるようにする。

その場で遊びを試せるようにする。ページを跨がないと触れない、だと離脱しやすい。閉じたままでは、箱を持ち上げるなどの本番の操作は出さない。

解説は開いたときに付ける。閉じたカードには出さない。ラベル「解説」の下に、行き先のページ名をリンクで出す。ボタンにはしない。`/{slug}` へ行く。1枚目のタイトルはリンクにしない。カード全面を一つのリンクにもしない。開いたあとの遊びは、操作（ドラッグなど）を受け取る。

タグはその手前で、`/?catalog=&tag=` へ行く。押しやすいよう余白を広めにする。

主に見るのはスマホなので、カーソル変化だけを手がかりにしない。合図は、閉じているときの予告の動き、末尾の More、押した瞬間の反応。開いたあとに解説。どの展示もこの型。

タグはカード上では「これは何系か」の印。`#{ラベル}` のチップ。押すと `/?catalog=&tag=` の棚へ行く。クエリが無いときだけ、トップのランダム。ナビの「新着」は全件の登録日降順。

カタログは部屋（クイズ、数学、科学）。`tags/ja/tags.json`。子が展示に付く印。ナビにカタログを載せる。葉タグはナビに並べない。クイズの子は種別と難易度だけ。解法や題材を名前にしない（ヒントにしない）。読み物の展示は `#読み物` にトピック（思考実験、量子力学…）を足す。読み物は科学の配下。

棚は `?catalog=`（`?tag=` は任意）。上から名称、説明、配下のタグ。いまの `tag=` は押下中。押すと URL の `?` 以降は変わるが、ページは遷移せず列を入れ替える。押下中をもう一度押すと `?tag=` が外れる。

### シュレ猫カード

- 上: 説明（本文より大きく、上下に余白）
- 閉じた中身: タイトル「シュレディンガーの猫」が1枚目。そのあと4コマ（シュレディンガーと箱 → 持ち上げる → どうなる！？）。次へは下から押し上げ。最後の次も押し上げでタイトルに戻る。キャプションは付けない
- 開いた中身: 4コマは残す。下に、詳細と同じ箱を持ち上げる遊びと、解説（ページ名のリンク）
- タグ: `#読み物` `#思考実験` `#量子力学`

## ヘッダー

固定しない。スクロールしたら消える。全ページ共通。ハンバーガーにはしない。空間の窓枠であって、空間そのものではない。**一歩スクロールすれば、もうキャンバス**（展示の空間）だけが見える。

2 段にする。

```
[ ロゴ  サイト名 ]                      ← 1段目。押すとランダム順のトップ
[ last updated  2026.08.19 ]           ← 1段目の下。サイトの最終更新（ビルド日）。小さい
[ 実験場  about  新着  #クイズ  #数学  #科学 ]  ← 2段目。細い。リンクは横スクロール。部屋は nav.json、カタログは tags.json
```

1段目はサイトの顔。ロゴとサイト名（`ui.json` の `name`。猫好きなシュレディンガー）。押すとクエリ無しのトップへ戻る。タグ検索ボタンは置かない。カタログへの入口は2段目。

最終更新は展示ごとではない。サイトがいつ焼かれたかだけ。1段目の下。先頭に `last updated`。文字は小さく、`muted`。時刻は出さない（デプロイ時刻に見える）。日付だけ。展示の `published` は出さない。

2段目は行き先の列。実験場、about、新着（`/?order=published`）、そのあとカタログ。幅に収まらなくても折り返さず、横に流す。

タグの絞り込みは、カタログの棚の先頭でする。索引ページは持たない。

## フッター

詳細のいちばん下は関連なので、フッターは置かない。404 も窓枠を付けないので、フッターは置かない。

詳細と 404 以外は、同じフッターを置く。トップ、実験場、について。ヘッダーもフッターも固定しない。貼り付いたナビにしないから、一歩動くとキャンバスになる。読み切ったところ（この一覧の展示が尽きたとき、または追加 20 回目を足したとき。21 回目は無い）に顔がもう一度出る。

中心はシュレ猫のロゴ。押すとトップへ戻る。リンクをずらっと並べる場所にはしない。

## カタログの棚（`/?catalog=`）

ナビのカタログ、またはカードのタグ、の先。整理された展示の列。足し方・残し方・幅の収まりはトップと同じ。順だけ、投稿日の降順。クエリ無しのトップでは、このタグ列は出さない。

上から:

1. カタログ名称
2. 説明（`tags.json` のカタログ `description`。空なら枠を出さない）
3. 配下のタグ全部。いまの `tag=` は押下中のチップ。押すと列を入れ替える（ページ遷移にしない）
4. カード（投稿日の新しい順）

`?catalog=` だけなら配下のどれかが付いた展示。`?tag=` もあればそのタグ。カードのタグは必ずカタログを付ける。

## 実験場

案をつらつら書いていく場所。まだ展示にしていないもの、途中のアイデア、メモ。`/lab`。

トップのカード一覧には出さない。カードはタイトル、一文、中身の 3 つ。中身は HTML を入れるスロット。文字でも画像でもよい。ここが育って、遊べる形になったら展示へ移す。

## について

about us。CATC を載せる。中身は `docs/CATC.md`。「参加するには」でフォームを開く。Yes なら証書っぽい一枚。No はしゃれで未実装のメソッドを叩く（F12 向け）。本物の入会フォームではない。名称は仮のままでよい。

## 404

無いアドレスの着地。専用画面。詳細へは行かない。ナビにも出さない。

窓枠（ヘッダー・フッター）は付けない。頭の中央に「404 Not Found」。その下にシュレ猫の遊び。トップのカードを開いたとき・詳細の遊びと同一。HTML はページに埋め込む（カードだけ partial を取る）。説明も関連も出さない。遊びの下にロゴと「Back Home」。トップへ戻る。文言はページに直書き（`ui.json` には置かない）。

## 詳細

詳細は遊び、説明、関連の 3 つ。遊びは、トップのカードを開いたときに出るものと同一。説明と関連は詳細だけ。検索の着地はここ。

```
タイトル
  ↓
概要
  ↓
遊び
  ↓
説明
  ↓
関連
```

### シュレ猫の遊び

1. シュレディンガーっぽいマスコットと箱がある。箱の中の猫は最初から見えている
2. 箱をドラッグで持ち上げられる
3. 持ち上げているあいだ、シュレディンガーはドキドキする
4. 十分持ち上げて 0.3 秒キープすると、そこで固定する。途中で離すと下りる
5. 固定すると、シュレディンガーはホッとする。猫は両手を上げて腰をふりふりダンスする。ダンスは 1 枚の画像の左右反転
6. 固定したあとは、クリックか下へのドラッグで箱が下りる

### シュレ猫の説明

シュレディンガーの猫の思考実験についての説明を簡単に書く。深入りしすぎず、適度な理解感を促す。

---

## 関連

詳細の末尾に載せる。タグの自動一致ではなく、自分で `related.json` に書いた先だけ出す。片方向でよい。双方向にしたければ、両方のファイルに書く。

- 表示: 横スクロール
- 1 件: タイトルつき画像（OGP と同じ PNG）

見た目の細部（サイズ、件数、余白）は応相談。横スクロールと「タイトル＋画像」は崩さない。

## 公開の範囲

最初に揃えるもの:

- トップのカード一覧（1 つ目固定、以降ランダム）
- シュレ猫カード（末尾の More で開く。4コマは残す。解説は開いたとき）
- シュレ猫詳細（遊び＋説明。遊びはカードを開いたときと同じ。HTML は詳細に埋め込む）
- 404 専用画面（窓枠なし。頭の中央に 404 Not Found。シュレ猫の遊び。下にロゴと Back Home。説明・関連は出さない。HTML はページに埋め込む）
- タグを押すと `?catalog=&tag=` で、そのタグの展示が登録日の降順で並ぶ
- 棚の先頭（名称、説明、配下のタグ。押下中はいまの `tag=`）
- ナビのカタログ（`/?catalog=`）と新着（`/?order=published`。全件の登録日降順）
- ヘッダー2段（ロゴとサイト名 + ナビの横スクロール）。固定しない
- フッター（ロゴとサイト名）。詳細と 404 以外は同じ。詳細と 404 には置かない
- 関連の枠（中身は展示が増えてから）

後で足すもの:

- 2 個目以降の展示
- 実験場の殻と lab カードの型（タイトル・一文・中身スロット）
- 実験場の個別の案（monty-hall の文面など）
- についての文面（CATC。CATC の日は開始の周年）
- 関連の見た目の詰め
